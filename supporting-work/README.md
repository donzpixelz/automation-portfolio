# Supporting Work

A few additional systems that show the range of work without turning the portfolio into a documentation archive.

## Customer Intake / Human Review

A low-friction intake path for broken AI systems, workflows, automations, integrations, agents, and unfinished prototypes. The system captures the person first; human review determines what is actually wrong and what happens next.

## Codex Launcher

A controlled interface for AI-assisted implementation work, with explicit task context, permissions, result capture, and verification rather than treating an AI run as an unbounded coding session.

## ChatGPT Project & Conversation tooling

Exact-ID project and conversation operations with ambiguity rejection, readback, and canonical archive behavior.

## Evidence-gated process analysis

Research and qualification work that establishes real operational friction before treating a manual process as an automation target.

## Other

The broader work includes API/webhook integrations, workflow repair, Google Ads data/reporting, Cloudflare systems, browser tooling, testing, verification, and technical handoff.
