# TrafficMonitor

**See real website visitor/session behavior and preserve trustworthy paid-traffic attribution.**

## Why it exists

Paid traffic is difficult to reason about when the original attribution gets overwritten by later sessions or repeat clicks. TrafficMonitor keeps the evidence intact and separates first-touch attribution from later session behavior.

## What it does

- Captures first-party visitor and session events.
- Preserves original paid-traffic attribution.
- Tracks later sessions and repeat paid clicks separately.
- Provides operational views for investigating real visitor behavior.
- Preserves historical evidence for later analysis.

## Built with

**Cloudflare Workers · D1 · R2 · TypeScript · Google Ads API / GAQL**
